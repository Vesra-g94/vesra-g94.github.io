Installing Pix’n Portal on Batocera

Pix’n Portal is a lightweight launcher for accessing the Team Pixel Nostalgia portal directly from Batocera through an existing RGS installation.

Pix’n Portal is designed to integrate with an existing RGS installation and launch the portal through a supported web browser without requiring the user to leave the normal Batocera interface.

Full and Lite Builds

Pix’n Portal Full includes the browser setup along with the optional qBittorrent installation prompt.

Pix’n Portal Lite removes the qBittorrent portion and is intended for systems where only portal access is needed.

Requirements

Before installing Pix’n Portal, make sure:

  • Batocera is installed and working.
  • RGS is installed.
  • Your RGS .api files are located in:
/userdata/rgs/download_services

Pix’n Portal depends on RGS for the actual portal content and download services.

Browser Support

Pix’n Portal checks the system for a compatible browser. If a supported browser is not already installed, the launcher can assist with installing one.

The launcher has been successfully tested with both Chrome and Firefox.

Installation

Place the Pix’n Portal launcher package on the Batocera system and extract it while preserving Linux permissions.

The launcher itself belongs in the Batocera Ports environment so it can be started directly from EmulationStation.

After installation, refresh the game list or restart EmulationStation if the new entry does not appear immediately.

First Launch

Launch Pix’n Portal from the Ports collection.

On the first run, the launcher will:

  1. Check for an available browser.
  2. Offer to install one if necessary.
  3. Launch the Pix’n Portal website.
  4. Hand supported content off to the installed RGS system.

The Full version may also offer to install qBittorrent.

Which Build Should You Use?

Use Full if you want the optional qBittorrent setup included.

Use Lite if you already have everything you need or simply want the smallest possible launcher.

Both versions provide the same core Pix’n Portal experience.

Notes

RGS updates may replace or remove custom runtime components installed outside the normal RGS environment. Your ROM files are not affected, but custom configuration or runtime files may occasionally need to be restored.
