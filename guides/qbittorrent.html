qBittorrent Launcher for Batocera

A simple Ports entry that gives Batocera users a convenient way to start qBittorrent directly from EmulationStation.

The goal is straightforward: install qBittorrent once, then launch it from the Ports collection instead of opening the F1 menu every time.

What It Does

  • Starts qBittorrent from Batocera.
  • Places it in the Ports menu.
  • Avoids the need to manually navigate through the desktop interface.
  • Keeps the setup simple and lightweight.

Installation

Install qBittorrent on the Batocera system, then place the launcher script in:

/userdata/roms/ports

Refresh the game list or restart EmulationStation if the new Ports entry does not appear immediately.

Launching

Open Ports → qBittorrent. The launcher starts qBittorrent using the existing Batocera installation.

Notes

This launcher does not replace or modify qBittorrent itself. It simply provides a cleaner way to access it from the normal Batocera interface.

That keeps the setup easy to maintain and easy to remove if it is no longer needed.
